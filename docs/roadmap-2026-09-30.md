## 数据与兼容性

- 数据库 v2 → v3 自动迁移，旧记录 `source` 置 `gps`、标题备注为空；`session_id` 幂等语义不变。
- PR 计算：新记录用 `elapsed_ms`（不含暂停）；旧记录回退壁钟时间，暂停会计入（旧数据无暂停信息，尽力而为）。滑窗只在单个连续段内进行——run-walk 高频暂停场景 PR 会偏保守，这是有意为之。
- 语音/文件选择在鸿蒙端为已知降级项；iOS Swift 侧无法在 Windows 编译验证，需按 iOS 指南在 Mac 构建。
