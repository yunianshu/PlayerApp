# 2027 厦门马拉松训练计划

目标比赛：2027-01-10；日历范围：2026-10-23 至 2027-01-10（80天）。暂定5小时15分，破5仅作挑战目标。

## 已接入
- 首页「2027厦门马拉松训练计划」入口
- 内置80天日期、训练类型、距离、参考配速和训练说明
- 每日训练手动完成标记，持久化本地 SharedPreferences
- 已有跑步记录按本地训练日期汇总显示为「已记录公里数」，但**不会自动标记完成**
- 每日疼痛(0–10)和疲劳(0–10)记录，达到风险值显示调整建议，不自动增加跑量
- Android 系统训练提醒：页面打开右上角通知图标设置时间；打开提醒开关后注册所有未来训练日（含休息日），修改时间会替换旧提醒，关闭会取消
- Android 闹钟使用 AlarmManager.setAndAllowWhileIdle，不需要精准闹钟权限。系统可能延迟派发，**不保证严格精确到分钟**；BOOT_COMPLETED、MY_PACKAGE_REPLACED 恢复待触发提醒
- Android 13+ 首次启用提醒时申请通知权限；若拒绝则不会显示通知，需去系统设置授权
- 数据全部保存在本机，不依赖服务器

## 已知平台差异及未完成项
- 当前原生系统定时提醒仅 Android 实现；iOS、HarmonyOS 会明确提示不支持，不能宣称跨三端可用
- 训练日历与完成记录、疼痛疲劳反馈还未纳入应用既有 JSON 备份导出
- 已有跑步只按日期汇总，同日多次跑步也会汇总；仍由用户确认完成；暂不做跑步与任务的强制一对一自动关联
- 疼痛、疲劳反馈只提供安全建议，不会未经确认修改训练计划
- 尚需 Flutter SDK 本地及 Android 真机验证；CI 必须跑 flutter analyze/test

## 测试与验收
在 app 目录运行：
```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```
安卓真机必须验证：授权/拒绝通知权限、锁屏触发、同一天提示、修改时间、关闭提醒、重启及更新后恢复、错过时间不补发、通知点击打开 App、跑步记录按日汇总、记录反馈及卸载重装。

本计划是可调整建议，不是强制训练处方。持续疼痛或影响步态时应暂停训练并评估。
